## 6. 安全与数据边界确认

逐项勾选：

- [ ] MQ中不包含完整地址数组；
- [ ] MQ中不包含数据库密码、Token或Access Secret；
- [ ] 下游只读账号不能写入业务表；
- [ ] 下游只读账号可查询`dispatch_assist`和`ai`完整业务schema；
- [ ] 热词加载和地址机器人不共用数据库账号；
- [ ] 生产REST经过网关认证与TLS；
- [ ] 不记录手机号、录音或完整报警对话；
- [ ] 日志只记录必要的`requestId/eventId/scopeId`；
- [ ] 已确定句柄TTL和消费失败保留时间；
- [ ] 已配置数据库、Outbox积压和消费失败告警。
